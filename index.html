Capabilities

        
Why Adobe Creative MCP?

        

          Built by motion designers and engineers to bridge the gap between Large Language Models and Adobe Creative Cloud.
        

      


      

        

          
🎛️

          
Dual-Host Architecture

          

            Unified CEP panel installer and runtime supporting both After Effects 2022+ and Photoshop 2021+ with automatic host discovery.
          

        


        

          
🔄

          
Coordinated Cross-App Flow

          

            Modify PSD text in Photoshop and automatically signal After Effects to reload the linked asset with zero manual refresh steps.
          

        


        

          
🔬

          
Headless PSD Probing

          

            Read layer trees, bounds, canvas sizes, and text content directly via Python psd-tools without even launching Photoshop.
          

        


        

          
🛡️

          
100% Local & Private

          

            Zero cloud dependencies. High-resolution raw PSDs, project aep files, and footage never leave your workstation.
          

        


        

          
⏪

          
Reversible & Safe Workflows

          

            Copy-first safeguards, explicit layer path addressing, and typed commands prevent accidental corruption of production masters.
          

        


        

          
🌐

          
Universal Agent Support

          

            Seamlessly plug into Claude Desktop, Google Antigravity, OpenAI Codex, Cursor, Zed, Windsurf, or custom Node.js agents.
          

        

      

    

  


  
  

    

      

        
Setup Guide

        
Get Running in Under 2 Minutes

        

          Simple PowerShell installation, automatic panel deployment, and standardized MCP agent configuration.
        

      


      
      

        

          STEP 01
          
Run Windows Installer

          

            Run install_windows.ps1 in PowerShell to register CEP panels for both AE and Photoshop.
          

        


        

          STEP 02
          
Open Extension Panels

          

            In AE and Photoshop: Window > Extensions > Adobe Creative MCP. Host daemons auto-start.
          

        


        

          STEP 03
          
Add Agent MCP Config

          

            Copy the JSON configuration below into your AI Agent's MCP settings file.
          

        


        

          STEP 04
          
Command Your Agent

          

            Ask your agent: 'Probe dialog.psd, change the title to Japanese, and refresh AE!'
